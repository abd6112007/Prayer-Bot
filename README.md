# 🕌 بوت مواقيت الصلاة — غزة (واتساب + GitHub Actions)

يرسل تنبيهاً منسّقاً إلى مجموعات واتساب محددة عند دخول وقت كل صلاة، ويعمل مجاناً على GitHub Actions.

- **المواقيت:** Aladhan API لمدينة غزة، تُجلب تلقائياً كل يوم (وتُحمَّل مواقيت الغد مسبقاً).
- **الإرسال:** مكتبة [Baileys](https://github.com/WhiskeySockets/Baileys) (اتصال مباشر بلا متصفح، فالجلسة صغيرة وسريعة).
- **التشغيل:** نسخ متعاقبة، كل منها ~5 ساعات و35 دقيقة، تتسلّم من بعضها (انظر `.github/workflows/prayer-bot.yml`).

## هيكل المشروع

```
src/
  config.js        الإعدادات (متغيرات البيئة)
  prayerTimes.js   جلب المواقيت من Aladhan وتحويلها إلى مواعيد بتوقيت غزة
  message.js       صياغة رسالة تنبيه الصلاة
  welcome.js       رسالة الترحيب (تُرسل مرة واحدة لكل مجموعة)
  adhkar.js        أذكار الصباح والمساء (الأوقات والصور)
  scheduler.js     يقرر متى يُرسل، ويمنع التكرار، ويعيد المحاولة
  whatsapp.js      الاتصال بواتساب وإعادة الاتصال
  state.js         يتذكر ما أُرسل (يمنع التكرار بين النسخ المتعاقبة)
  index.js         نقطة التشغيل
scripts/
  login.js         الربط الأول بـ QR
  groups.js        عرض المجموعات ومعرّفاتها
  test-send.js     رسالة تجريبية للمجموعات
  preview.js       عرض مواقيت اليوم وشكل الرسالة (بدون واتساب)
  session.js       تشفير/فك تشفير الجلسة
.github/workflows/prayer-bot.yml
```

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run login` | ربط رقم البوت (يعرض QR) |
| `npm run groups` | عرض المجموعات ومعرّفاتها |
| `npm run preview` | مواقيت اليوم + شكل الرسالة (`npm run preview -- Maghrib`) |
| `npm run test-send` | رسالة تجريبية للمجموعات في `GROUP_IDS` |
| `npm run dry-run` | تشغيل البوت بدون واتساب (يطبع الرسائل في الشاشة) |
| `npm run pack-session` | تشفير الجلسة إلى `session.enc` |
| `npm start` | تشغيل البوت محلياً (للاختبار فقط) |

## الإعدادات

انظر `.env.example`. المهم منها:

| المتغير | الوصف |
|---|---|
| `SESSION_PASSPHRASE` | (سرّي) كلمة سر تشفير الجلسة، 32 حرفاً عشوائياً فأكثر |
| `GROUP_IDS` | (سرّي) معرّفات المجموعات مفصولة بفاصلة — البوت لا يرسل لغيرها |
| `PRAYER_METHOD` | طريقة الحساب (الافتراضي 5 = الهيئة المصرية). قارنها بجدول وزارة الأوقاف |
| `PRAYER_TUNE` | تعديل بالدقائق لكل وقت (مثلاً `0,0,0,0,0,0,0,0,0`) |
| `PRAYER_SCHOOL` | 0 جمهور (افتراضي) / 1 حنفي (يؤثر على العصر) |
| `HIJRI_ADJUSTMENT` | ‎+1 / -1 لتعديل التاريخ الهجري إن اختلف عن التقويم المحلي |
| `SEND_WELCOME` | `false` لتعطيل رسالة الترحيب (الافتراضي: تُرسل مرة واحدة لكل مجموعة) |
| `WELCOME_VERSION` | غيّرها إلى `2` لإعادة إرسال الترحيب لكل المجموعات بعد تعديل نصه |
| `DISCONNECT_LIMIT_MINUTES` | إن تعذّر الاتصال بواتساب أكثر من هذه المدة تنتهي النسخة بخطأ واضح (الافتراضي 10) |

على GitHub: الأسرار في **Settings → Secrets and variables → Actions → Secrets**، والإعدادات الاختيارية في **Variables**.

## صيانة

- **تطبيق تعديل جديد فوراً:** النسخة الجارية تبقى بالكود القديم حتى تنتهي (حتى 5.5 ساعات)، وأي تشغيل يدوي يقف في الطابور خلفها. لتفعيل التعديل الآن: Cancel للنسخة الجارية ثم Run workflow.
- **إيقاف البوت:** تبويب Actions ← الـ workflow ← ⋯ ← *Disable workflow*، ثم *Cancel run* للنسخة الجارية.
- **ظهر الـ workflow بالأحمر بعد كود خروج 2:** الجلسة لم تعد صالحة (خروج من الجهاز المرتبط). أعد `npm run login` ثم `pack-session` وارفع `session.enc` الجديد إلى فرع `session-data` (استبدله).
- **كود خروج 5:** لم ينجح الاتصال بواتساب من خادم GitHub لمدة 10 دقائق. ابحث في السجل عن سطور `انقطع الاتصال (كود: …)`.
- **كود خروج 3:** نسخة أخرى تستخدم نفس الجلسة (مثلاً شغّلت البوت على جهازك أثناء عمله على GitHub).
- **إضافة مجموعة جديدة لاحقاً:** أضف رقم البوت للمجموعة، ثم على جهازك نفّذ `npm run login` **في مجلد جديد** (يُنشئ جهازاً مرتبطاً ثانياً)، شغّل `npm run groups`، أضف المعرّف إلى سرّ `GROUP_IDS`، ثم احذف ذلك الجهاز من واتساب ← الأجهزة المرتبطة. لا تستخدم مجلد `data/` القديم أبداً بعد رفعه.
- **بعد أي تغيير في توقيت غزة (الصيفي/الشتوي):** شغّل `npm run preview` وقارن الأوقات بجدول محلي.
